================================================================================
                          HOW TO RUN BENCHMARK
================================================================================

Build:
  cmake -B build -DCVEDIX_WITH_SEETAFACE=ON
  cmake --build build

Run Performance Benchmark:
  ./build/bin/benchmark_face_recognizer_sample [model_dir] [video] [duration]

Run Accuracy Benchmark:
  ./build/bin/benchmark_face_recognizer_sample --accuracy

Download LFW Dataset:
  ./build/bin/benchmark_face_recognizer_sample --accuracy --download

Custom Options:
  --accuracy              Run accuracy benchmark
  --dataset=lfw           Dataset name (default: lfw)
  --model=/path/to/models Model directory
  --root=/path/to/datasets Dataset root directory
  --download               Download dataset only
  --similarity-th=0.33    Set similarity threshold
