Detailed Description

Base class for primary inference nodes (full-frame detection)

Primary infer nodes perform inference on the entire frame to detect objects. This is typically the first inference stage in a pipeline.

Primary vs Secondary Inference

Type Input Use Case
Primary Full frame Object detection, face detection
Secondary Cropped regions Classification, attribute extraction
