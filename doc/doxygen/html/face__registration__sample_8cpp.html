Detailed Description

Sample demonstrating face registration with augmentation.

Supports both IMAGE and VIDEO input:

Usage: ./face_registration_sample <input_path> <person_name>

Examples: ./face_registration_sample ./person.mp4 "John Doe" # Video input ./face_registration_sample ./photo.jpg "Jane Smith" # Image input ./face_registration_sample ./photos/ "Alice" # Directory of images
