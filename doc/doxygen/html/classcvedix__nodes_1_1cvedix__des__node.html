Detailed Description

Base class for all destination nodes.

Destination nodes are the endpoints of video analytics pipelines. They consume processed frame_meta and output to external targets.

Key Features

  • Single Channel: Each destination operates on one channel
  • Status Reporting: Real-time FPS and latency monitoring
  • No Output: Does not push meta to next nodes (terminal)
Note
This is an abstract base class. Use concrete implementations like cvedix_screen_des_node or cvedix_rtmp_des_node.
