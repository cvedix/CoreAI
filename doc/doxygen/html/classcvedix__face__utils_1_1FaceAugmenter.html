Detailed Description

Face augmenter for overlaying glasses, masks, hats on aligned faces.

Uses 5-point facial landmarks: [0] left eye, [1] right eye, [2] nose, [3] left mouth, [4] right mouth

Reference landmarks for 112x112 aligned face (InsightFace standard): left_eye: (38.29, 51.70), right_eye: (73.53, 51.50) nose: (56.03, 71.74), left_mouth: (41.55, 92.37), right_mouth: (70.73, 92.20)
