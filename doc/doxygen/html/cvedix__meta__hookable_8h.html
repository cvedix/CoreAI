Detailed Description

Hookable interface for monitoring metadata flow through nodes.

This file defines the cvedix_meta_hookable class which allows attaching callbacks (hooks) to monitor metadata at 4 different ports in a node:

  • Arriving: When metadata enters the input queue
  • Handling: When metadata is being processed
  • Handled: When metadata processing is complete
  • Leaving: When metadata exits the output queue
