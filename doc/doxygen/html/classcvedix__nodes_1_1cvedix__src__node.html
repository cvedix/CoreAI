Detailed Description

Base class for all source nodes.

Source nodes are the starting point of video analytics pipelines. They generate cvedix_frame_meta objects containing video frames and push them to downstream processing nodes.

Key Features

  • Single Channel: Each source node operates on one channel
  • Controllable: start()/stop() methods control data generation
  • Stream Info: Provides original video dimensions and FPS
  • Resize Support: Optional frame resizing for performance
Note
This is an abstract base class. Use concrete implementations like cvedix_file_src_node or cvedix_rtsp_src_node.
