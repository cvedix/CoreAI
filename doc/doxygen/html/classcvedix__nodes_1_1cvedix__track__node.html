Detailed Description

Base class for multi-object tracking nodes.

Provides infrastructure for tracking detected objects across frames, assigning persistent IDs, and maintaining track histories.

Processing Pipeline

  1. preprocess(): Extract bounding boxes and features from frame_meta
  2. track(): Run tracking algorithm (pure virtual - implement in derived)
  3. postprocess(): Write track IDs back to frame_meta
Note
This is an abstract base class. Use cvedix_sort_track_node or cvedix_dsort_track_node.
