Detailed Description

Base class for secondary inference nodes (ROI-based inference)

Secondary infer nodes perform inference on cropped regions (ROIs) from primary detection results. This enables multi-stage pipelines.

Pipeline Flow

Frame → Primary Infer → Detections → Secondary Infer (on each ROI) → Attributes

Target Filtering

Secondary inference can be filtered by:

  • Primary class ID (p_class_ids_applied_to)
  • Minimum target size (min_width_applied_to, min_height_applied_to)
