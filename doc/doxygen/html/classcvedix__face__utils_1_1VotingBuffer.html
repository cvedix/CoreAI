Detailed Description

Temporal Voting Buffer for stable face recognition.

Collects recognition results over time and returns the majority vote. This reduces flickering and improves stability in video streams.

Example: If last 10 frames show [A,A,B,A,A,A,C,A,A,A], result is "A"
