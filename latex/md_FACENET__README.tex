{\bfseries{Q\+: Face\+Net vs Insight\+Face -\/ which should I use?}}

A\+:
\begin{DoxyItemize}
\item Face\+Net\+: Good for facenet-\/pytorch compatibility
\item Insight\+Face\+: Better performance and accuracy (recommended)
\end{DoxyItemize}

{\bfseries{Q\+: How accurate is Face\+Net?}}

A\+: 99.\+2\% on LFW dataset (VGGFace2 model)

{\bfseries{Q\+: Can I use my own trained model?}}

A\+: Yes! Export to ONNX with the provided script\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{python\ export\_facenet\_to\_onnx.py\ -\/-\/model\ your\_model.pth}

\end{DoxyCode}


{\bfseries{Q\+: Why is MTCNN not fully implemented?}}

A\+: Yu\+Net provides better performance with similar accuracy. MTCNN is 3-\/stage (slow) while Yu\+Net is single-\/stage (fast).

{\bfseries{Q\+: How to improve accuracy?}}

A\+:
\begin{DoxyEnumerate}
\item Enable face alignment
\item Use high-\/quality images for registration
\item Register multiple photos per person
\item Adjust matching threshold
